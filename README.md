# Intelligent Compliance Assistant

## Overview
This project contains a multi-agent AI system using Azure AI Foundry, Semantic Kernel, and Azure AI Search services.

## Setup Instructions

1. Copy `.env` from `.env.example` (or provided template) and fill in your Azure credentials and endpoints.
2. Create a Python virtual environment and activate it.
3. Install dependencies using `pip install -r requirements.txt`.
4. Run the main app with `python main.py`.

## Deployment
Refer to Azure documentation for deploying Python apps on Azure App Service or Functions.
